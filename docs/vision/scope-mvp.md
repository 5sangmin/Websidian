# MVP Scope

## MVP Goal

Websidian의 첫 번째 목표는 “읽기 중심 공개 Vault”를 만드는 것이다.
즉, 사용자가 자신의 Vault를 웹에서 공유하고, 방문자가 대표 문서부터 시작해 Markdown과 HTML 문서를 탐색할 수 있도록 하는 것이 MVP의 목적이다.

MVP는 제품의 모든 가능성을 구현하는 단계가 아니라, 가장 핵심적인 사용자 가설을 검증하는 단계다.
따라서 초기 버전은 아래 질문에 답할 수 있어야 한다.

- Vault 중심의 문서 공유 모델이 유효한가?
- 대표 문서 기반 탐색 방식이 자연스러운가?
- Markdown과 HTML을 함께 다루는 문서 경험이 실제로 가치가 있는가?

## Primary User Journey

MVP에서 가장 중요한 사용자 흐름은 다음과 같다.

1. 사용자가 Vault를 만든다.
2. 대표 문서(main.md 등)를 지정한다.
3. Markdown 문서를 업로드하거나 등록한다.
4. HTML 문서를 내부 문서처럼 등록한다.
5. 방문자는 대표 문서에서 읽기를 시작한다.
6. 내부 링크를 따라 다른 문서로 이동한다.
7. 필요하면 HTML 문서를 열거나 임베드된 HTML을 본다.

## In Scope

MVP에 포함할 기능은 다음과 같다.

### 1. Vault 관리
- Vault 생성
- Vault 목록 조회
- Vault 기본 메타데이터 관리
- 대표 문서 지정

### 2. Markdown 문서 처리
- Markdown 문서 등록
- Markdown 렌더링
- 내부 링크 이동
- 이미지/PDF 같은 첨부파일 참조

### 3. HTML 문서 처리
- HTML 문서 등록
- HTML 문서를 내부 문서처럼 조회
- Markdown 문서에서 HTML 문서로 내부 링크 연결
- Markdown 문서 안에 HTML 문서 임베드

### 4. 최소 문서 라우팅
- Vault 단위 URL 구조
- 문서 상세 페이지
- 대표 문서 진입 구조
- 문서 타입별 렌더러 분기

### 5. 최소 인프라
- Docker Compose 기반 로컬/홈랩 개발 환경
- PostgreSQL 기반 메타데이터 저장
- MinIO 기반 파일 저장

## Out of Scope

MVP에서는 다음을 제외한다.

### 1. 편집 기능 고도화
- 웹 기반 실시간 편집
- 동시 편집 충돌 해결
- Obsidian 에디터 완전 복제

### 2. 협업 기능
- 팀 단위 협업 워크스페이스
- 초대/승인 플로우
- 세밀한 역할 기반 권한 모델

### 3. 고급 탐색 기능
- 고급 그래프 필터링/커스터마이징
- 전문 검색 엔진 연동
- 추천 알고리즘 기반 관련 문서

### 4. 고급 운영 기능
- 멀티테넌시 SaaS
- 과금/구독
- 외부 OAuth 연동
- 대규모 운영용 관측/분석 시스템

## MVP Success Criteria

MVP는 아래 조건을 만족하면 성공으로 본다.

- Vault 하나를 생성하고 대표 문서를 지정할 수 있다.
- Markdown 문서가 웹에서 읽기 좋게 렌더링된다.
- 내부 링크를 따라 문서 이동이 가능하다.
- HTML 문서를 내부 문서처럼 열 수 있다.
- Markdown 안에 HTML 문서를 임베드할 수 있다.
- 첨부파일 메타데이터와 실제 파일 저장이 분리되어 동작한다.

## MVP Risks

초기에 특히 주의해야 할 위험은 다음과 같다.

- Markdown/HTML 문서 모델이 너무 복잡해질 위험
- HTML 임베드의 보안 문제(iframe, sandbox, CSP 등)
- 문서 링크 규칙이 파일 경로와 URL 사이에서 꼬일 위험
- 그래프/백링크까지 초기에 욕심내다 MVP가 비대해질 위험

## Post-MVP Priorities

MVP 이후 바로 검토할 확장 기능은 다음과 같다.

1. 백링크
2. 기본 그래프 뷰
3. 태그/카테고리 탐색
4. 버전 관리
5. 사용자/권한 관리
6. 검색 고도화

## Definition of Done

MVP 완료의 기준은 다음과 같다.

- 문서 구조와 저장소 구조가 ADR/문서와 일치한다.
- Docker Compose로 개발 환경이 올라온다.
- 대표 문서 기반 탐색이 동작한다.
- Markdown과 HTML 문서가 최소 기능 수준에서 함께 동작한다.
- README와 docs 문서가 현재 구현 상태를 반영한다.

## Summary

Websidian MVP는 “Obsidian 스타일 공개 Vault를 웹에서 읽고 탐색하는 최소 제품”이다.
핵심은 기능 수를 늘리는 것이 아니라, Vault 모델, 대표 문서 진입, Markdown 렌더링, HTML 내부 문서화라는 제품 가설을 가장 작은 단위로 검증하는 것이다.
