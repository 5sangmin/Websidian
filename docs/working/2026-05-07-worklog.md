## Decisions

- Docker Compose에서는 `latest` 태그를 사용하지 않고, 항상 명시적인 버전 태그를 사용한다.
  - PostgreSQL: `postgres:16.13` (검증된 16 계열 안정 버전)
  - MinIO: `minio/minio:RELEASE.2025-10-15T17-29-55Z` (보안 패치가 포함된 release 태그)
- Compose 파일에는 이미지 태그를 직접 하드코딩하지 않고, `POSTGRES_IMAGE` / `MINIO_IMAGE` 환경 변수로 관리한다.
- 환경 변수 이름/값 규칙:
  - Key: 대문자 snake_case, prefix(`APP_`, `POSTGRES_`, `MINIO_`, `VITE_` 등)로 범위를 드러낸다.
  - Value: 기본적으로 언더바(`_`) 사용, URL/엔드포인트 리소스에 한해서만 하이픈(`-`) 허용.
  - 계정/자격/비밀번호/버킷 이름은 모두 언더바 사용 (`websidian_pgsql`, `websidian_minio`, `websidian_minio_dev`, `change_me`).
- backend Spring Boot 기본 스택을 다음 조합으로 고정한다(ADR 0005로 기록).
  - Gradle Groovy, Java 17, Spring Boot 3.5.14, properties 기반 설정.
  - 초기 의존성: Spring Web + Spring Data JPA + PostgreSQL Driver + Actuator.
- backend health endpoint는 Actuator 기본 경로 `/actuator/health`를 사용하며, runbook에서 표준 헬스 체크로 취급한다.

## Problems / blockers

- 현재 MinIO bucket(`websidian_minio_dev`) 생성 전략은 아직 정해지지 않았다.
  - 컨테이너 초기화 스크립트에서 할지, backend 애플리케이션이 부트스트랩할지 후속 결정 필요.
- Flyway/Liquibase와 같은 DB 마이그레이션 툴은 아직 도입 전이라, `spring.jpa.hibernate.ddl-auto=update` 상태를 얼마나 길게 유지할지 결정해야 한다.
- Document/Version 스키마가 커질 것을 감안하면, 빠른 시점에 마이그레이션 도구를 도입하는 ADR/이슈가 필요하다.

## Out of scope discovered

- Document/Version 엔티티 설계, JPA 리포지토리, 서비스/컨트롤러, REST API는 오늘 범위에서 의도적으로 제외했다.
- Vault, Link, Tag, Permission, 파일 업로드/MinIO 연동 로직 등도 이번 세션에서는 손대지 않았다.
- CI/CD, GitHub Actions, 이미지 digest 고정, 운영용 compose 파일(`compose.prod.yml`) 등 배포/운영 관련 결정은 추후 단계로 미뤘다.
