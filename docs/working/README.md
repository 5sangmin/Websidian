# Working Notes

이 디렉토리는 Websidian의 진행 중 작업 문서, 임시 설계 메모, 세션 로그를 보관하는 공간이다.

여기에는 아래와 같은 문서를 둔다.

- 작업 시작 전 범위 정리 메모
- 구현 중 결정 사항 메모
- worklog
- PR 전 self-review 메모
- 정식 문서로 승격되기 전 초안

여기에는 아래 문서를 오래 유지하지 않는다.

- 이미 확정된 공식 구조 문서
- 장기 기준이 되는 운영 규칙 문서
- README 성격의 프로젝트 입구 문서

파일명은 가능한 한 날짜와 주제를 함께 적는다.

예:
- `2026-05-07-worklog-document-api.md`
- `2026-05-07-plan-graph-view.md`

작업이 끝난 뒤 아래 중 하나를 선택한다.

- 계속 참고할 가치가 있으면 남긴다
- 공식 문서로 승격할 내용이면 `docs/*` 적절한 위치로 옮긴다
- 의미가 사라진 임시 메모면 정리하거나 삭제한다
